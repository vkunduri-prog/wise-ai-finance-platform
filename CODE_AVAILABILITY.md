# Code Availability

The original WISE application source code is not included in this public portfolio repository.

This repository intentionally focuses on technical documentation:

- Problem definition
- Architecture
- Data flow
- Feature engineering
- Model design
- RAG and chatbot methodology
- Evaluation
- Engineering challenges
- Limitations and future work

This approach preserves the integrity of the original team project while still making the technical work reviewable by recruiters, engineers, and collaborators.

The documentation is not a substitute for a runnable production system. Any future source release should be reviewed for:

- Team permission and attribution
- Secrets and environment variables
- Personal or synthetic data files
- Model artifacts
- Third-party book or document licensing
- API-provider terms
