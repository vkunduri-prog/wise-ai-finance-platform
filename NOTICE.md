# Project Notice and Attribution

WISE (Wealth Investment & Strategy Engine) originated as an Arizona State University graduate capstone project.

This public repository is a documentation-focused portfolio representation maintained by **Vaishnavi Reddy Kunduri**. It explains the system architecture, modeling approach, retrieval design, evaluation, and engineering decisions, with emphasis on Vaishnavi's confirmed contribution.

The capstone was completed collaboratively. This repository does not claim that Vaishnavi solely designed or implemented every component. The official academic submission should be consulted for the complete author list and institutional attribution.

## Vaishnavi Reddy Kunduri's Documented Contribution

Her work focused on:

- Financial-data preprocessing and transaction normalization
- Feature engineering for user-level financial analytics
- Risk-classification and anomaly-detection workflows
- Retrieval design using sentence-transformers, ChromaDB, and BM25
- User-context construction for the financial chatbot
- FastAPI integration of analytical and AI outputs
- Validation, caching, retries, and structured error handling

## Data and Performance Notice

Performance values shown in this repository come from academic evaluation using synthetic or simulated financial profiles. They should not be interpreted as production guarantees.

No private user financial data, credentials, API keys, or personal banking records are included.
